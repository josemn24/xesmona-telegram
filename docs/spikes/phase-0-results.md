## Findings for the ADRs

- callback_data: longest seen 41 bytes for a move (`ttt:<32-char id>:<cell>:<version>` with a 2-digit version), leaving 23 bytes of margin under the 64-byte limit (G2).
- Message edits work in a basic group and in a private chat; callbacks there also carry `chat_instance` (G2).
- Vs bot: applying the human move and the bot reply together gives one edit per turn (G2, ADR 0005).
- Inline messages can be edited through `inline_message_id` like chat messages (I3).
- Inline callbacks have no `chat`, but `chat_instance` is present and equals the value seen for callbacks in the same chat: usable to group inline games by chat (I3).
- Privacy mode on does not block `/cmd` or `/cmd@bot` in basic groups or supergroups (G1).
- Forum topics: replies need `message_thread_id` from the command; edits keep the message in its topic (G5).
- Inline messages are identified only by `inline_message_id`: Phase 1 must store it as the message key for inline games (I2).
